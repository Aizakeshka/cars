# 🚗 Sports Car React — Каталог спортивных автомобилей

Добро пожаловать в Sports Car React — современное React-приложение с каталогом спортивных автомобилей.  
Проект демонстрирует работу с компонентами, состоянием, фильтрацией данных и адаптивным интерфейсом.

Приложение выполнено в динамичном стиле с акцентом на скорость, мощность и минимализм.

---

## 🚀 Возможности

- 🔍 Просмотр каталога спортивных автомобилей  
- 🏎️ Карточки автомобилей с подробной информацией  
- 📊 Отображение характеристик (мощность, разгон, скорость)  
- 🎨 Современный и адаптивный UI  
- ⚡ Быстрая работа благодаря Vite  
- 📱 Поддержка мобильных устройств  

---
